Workspace Quote PDF — Support

Workspace Quote PDF is a Google Sheets add-on that groups line-item rows by Quote ID and creates one branded quotation PDF per quote.

Get help

Email happylife2080100@gmail.com. We aim to reply within a few business days. To report a bug, see the report an issue page.

Common questions

  • Where are my PDFs? In the output folder shown in the sidebar (default Quote PDFs), linked from the Quote PDF results tab.
  • Why is a quote blocked? Its rows disagree on customer or currency, or a required value is missing/invalid. The sidebar lists the affected row numbers.
  • Why did generation use my free allowance? Only successful, newly created PDFs count. Failures and identical retries do not.
  • Can I choose an existing Drive folder? Only folders the add-on can access are listed; use New folder or keep the default.
  • The sidebar shows a permission/storage error. This happens with multiple Google accounts signed in; use a browser profile with a single account (or an Incognito window).

Uninstall / data

See the privacy policy. Output PDFs and the results tab are yours; remove them from Google Sheets / Drive directly.
